4. MISSING-ADDRESS IMPACT & KEY INSIGHTS
--------------------------------------------------------------------------------
1. Missing Secondary Address Impact:
   - Approximately 4.46% of secondary-source entities have completely empty addresses.
   - Requiring a strict address similarity threshold unconditionally drops recall by 1.21% (92,724 true matches discarded!).
   - Missing-tolerant evaluation restores those matches while precision remains governed by strong name matching.

2. Precision vs Recall Trade-off:
   - Simple Baseline (Norm Name + Country) achieves: Recall = 22.69%, Precision = 7.40%, F1 = 0.1116.
   - Adding address filtering (tolerant) improves precision from 7.40% to 18.53% (+11.12%).

5. RECOMMENDED THRESHOLDS & RULES FOR NEXT STAGE (BLOCKING & ML MODEL)
--------------------------------------------------------------------------------
1. Blocking Infrastructure Recommendations:
   - Country is mandatory: 100% of true matches have equal normalized country. Never compare entities across different countries.
   - Multi-Tier Blocking Union:
       Tier 1: Exact Normalized Business Name + Country (high precision core).
       Tier 2: Business Name First 5-Character Prefix + Country (captures spelling typos and abbreviations).
       Tier 3: Name Token Inverted Index + Country (captures word order inversions like 'Global Tech' vs 'Tech Global').
   - Union of these blocking passes will expand recall beyond 90% while keeping candidates well below 35M.

2. Matching & Feature Engineering Recommendations:
   - Handle Missing Addresses Explicitly:
       * Add a binary feature `is_address_missing`.
       * When address is present, compute Jaro-Winkler, Token-Sort, and Levenshtein similarity.
       * When address is missing, impute a neutral score (or separate pathway) so valid name matches are not penalized.
   - Business Name Features:
       * Jaro-Winkler similarity on normalized name (captures typos).
       * Token Jaccard / Token Set Ratio (captures dropped or reordered tokens).
       * Length ratio and prefix match length.
   - Recommended Decision Threshold:
       * If business name JW >= 0.92 and address missing -> HIGH CONFIDENCE MATCH.
       * If business name JW in [0.75, 0.92] and address JW >= 0.70 -> HIGH CONFIDENCE MATCH.
       * If address JW < 0.35 and address present -> REJECT (conflicting physical locations).
